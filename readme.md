# Bonjour, bienvenue dans l'application Stats

Ici, vous pouvez voir beaucoup plus de détails sur les élèves, avec des statistiques précises comme :

* Le pourcentage de filles par spécialité
* Toutes les triplettes de spécialités formées par l'ensemble des voeux
* Le filtrage de tous les élèves ayant fait un vœu pour une spécialité donnée, avec l'affichage des moyennes des matières importantes
* Le pourcentage d'élèves ayant fait des voeux parmi l'ensemble des élèves de 2nde
* Le pourcentage de voeux ayant reçu un avis favorable du conseil de classe

### Détails sur le travail

Les fonctions sont bien séparées dans différents modules pour rester organisé.

Temps de travail : environ 4 heures à la maison et 3 heures au lycée.

La structure a été pensée pour faciliter :
- la modification des chaînes de caractères qui peuvent changer selon la structure des CSV,
- l'ajout d'autres classes, pas seulement de 2nde, pour d'autres statistiques,
- les futures modifications liées aux fonctions.

## IMPORTANT:
Si la programme ne deroule pas:

- **No module named reportlab**: Voir le dossier "installation deps/" pour bien creer l'environnement necessaire.
- **Une erreur de DIRECTORY NOT FOUND**: la programme n'etait pas teste sur Windows et il y a la possibilite que une changement de "/" en "\\" ou "//" est necessaire en stats.py ligne 103.
